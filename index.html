Notes

    
    
Saved encrypted using your computer login (your Windows account, or the Linux keyring).
       The file cannot be read on another computer or account, but anyone using this app while signed in as you can read it.

    

    

      
      
      
      
    

  

  
    
Server management (iLO, iDRAC, BMC)

    
Servers have a small separate computer inside, the BMC (HPE iLO, Dell iDRAC, Supermicro, Lenovo XCC...). It stays on when the server is off,
       so Dashboard Hub can read the server's power state, health and temperatures, and switch it on. The login is stored encrypted and is never put in a backup.

Backup and sharing


    
Export

    
Saves your panels, servers, layout and network map to a file you can keep as a backup or send to a friend.
       The file contains your local addresses and server usernames.

    
    


    
Import

    
Loads panels, servers and the network map from a backup file. Only normal web addresses are accepted,
       and anything unusual in the file is skipped.

    
    


    

    

  

  
    
Updates

    

    

    

      
      
    

    

    
Or install from a file: choose the update file you were given (it ends in .hubupdate). The app checks it,
       installs it, and then needs to be closed and opened again. Your panels, notes, map and settings are kept.

    

      
Earlier versions kept on this computer

      
Dashboard Hub keeps a checked copy of the versions it ran, so you can go back if something stops working. Your panels, notes and settings are kept. Each copy takes about 1 MB.

      
      
No earlier versions are stored yet. When you install your next update, the version you are leaving is kept here.

      Security settings
      
    
      The standard settings suit most home and office networks. Protections that must never be switched off (pages kept apart from the app, every update file checked, scans and connections only to addresses inside your own network) are not listed here on purpose.
      
    
      
      
      Websites in your panels
      
      
      
      
      
      
      
      Only the websites you added and addresses inside your own network are ever allowed. Reload a panel after changing certificates.
      
    
      
    
      
      
      Scanning and connections
      
      
      
      
      
    
      
    
      
      
      Finding machines (no SNMP needed)
      
      
      
      
      
      
      
      
      Every machine is also read from the computer's own ARP table, and your router or controller connections (UniFi, MikroTik, OPNsense, OpenWrt and others) give lists of machines without SNMP. "Quiet scan" sends no pings and no port checks, so it only finds machines that announce themselves or were recently seen by this computer.
      
    
      
    
      
    
      
      
      
      
      
    
      
        

  
    
      About Dashboard Hub
      
    
      
    
      Your whole network and every tool you use to run it, in one desktop app. Free software under the GNU General Public License v3 or later: you can use it, study it, change it and share it, and if you share a changed version you share its source under the same license.
      
    
      Network ports it uses
      
    
      Everything starts from this computer, and it never opens a port for others to connect to. Only the update check and Cisco Meraki leave your own network. Routers and switches are only read, never changed. Useful if your network has a firewall.
      
    
      
      
      
        
      What it is forPorts
      
        
      
      
    
      
    
      Tip for SNMP: use version 3 or a read-only community with a name of your own (not "public"), and never expose it to the internet. Only scan networks you own or have permission to scan.
      
    
      
        

  
    
      Network boot (PXE)
      
    
      Starts another computer from this one, over the network cable, with no USB stick. Choose a disc image (ISO) or the netboot.xyz menu on that computer's boot screen.
       This is off until you press Start, and it stops when you close Dashboard Hub. It only answers the computers you list below, it never changes your router's settings,
       and the menu itself never installs or erases anything: a disc that offers an installer will ask you first.
      
    
      1. Which computer may network boot?
      
    
      Enter its MAC address (shown on the Network Map when you click it, or in its BIOS boot screen). Other computers on your network are left alone.
      
    
      
      
      
      
    
      
    
      
    
    
      2. Network connection to use
      
    
    
      Use a cable: network boot does not work over Wi-Fi. The booting computer must be on the same network as this one.
      
    
      3. Disc images to offer
      
    
      
    
      
    
      Ubuntu-style and Debian live discs start directly. Other ISO files are tried in a generic way and may not work on every computer. The menu also has netboot.xyz: many live, rescue and installer images, downloaded by the booting computer, so it needs internet.
       While this is running, other computers on your network can also see the menu and fetch the ISO files you added.
      
    
      
      Testing with a VirtualBox (or similar) virtual machine
      
        
        
      1. In the VM's Settings → System, tick Network in the boot order. Enable EFI can be on (modern PC style) or off (older BIOS style); if one does not work, try the other. Secure Boot must be off.
        2. 
        
      2. In Settings → Network, choose Bridged Adapter on your cable connection (not NAT; Wi-Fi often fails). Keep the adapter type Intel PRO/1000.
        3. 
        
      3. Copy the VM's MAC address (Network → Advanced) into box 1 above, and choose the same connection in box 2.
        4. 
        
      4. Press Start here, then start the VM. Seeing the "Dashboard Hub network boot" menu means it works.
        5. 
        
      5. If the VM says "No boot filename received", the answer never arrived: check the MAC, the connection, the bridge and the firewall.

      Router & switch links
      
    
      Dashboard Hub can ask your router, switches, access points or controller which devices they can see: names, which are on Wi-Fi
       or cable, and which switch port each one uses. It only ever reads lists; it never changes any setting.
       Logins are stored encrypted on this computer and are never put in a backup.
      
    
      
    
      
      Find devices that speak SNMP
      
      Asks each machine on your map whether it answers SNMP (the standard way switches and routers share their ports and traffic), then lets you add the ones that do with one click. Read-only. A device that has SNMP switched off, or uses a different community name, stays silent.
