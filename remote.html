Remote view

PiKVM, JetKVM and other web KVMs open here. NoMachine opens in its own NoMachine window.

Control a computer remotely

Add a device on the left, then click it to open it here.

  • PiKVM and JetKVM: see and control a computer's screen, keyboard and mouse through the small KVM box plugged into it. Sign in on the device's own page. Their self-signed certificates are accepted for the devices you add.
  • Other web KVM: any device or page that works in a browser (TinyPilot, BliKVM and similar).
  • NoMachine: remote desktop to a computer that runs NoMachine. NoMachine is separate, free software that you install yourself on this computer and on the one you want to control; Dashboard Hub only starts it with the connection filled in (the Add device form checks and links the download page).

Add a device

NoMachine is separate, free software. It is not part of Dashboard Hub.

You need it on two computers: NoMachine installed on this computer (to connect from), and NoMachine installed on the computer you want to control.
